# Sudoku

一个基于 Tauri + React + TypeScript 的桌面数独应用，包含完整的 9x9 棋盘交互、计时、提示、笔记模式和难度切换，适合作为桌面小游戏项目或 Tauri 练手作品。

## 项目简介

这个项目实现了一套完整的数独游玩流程：启动时自动生成新局，玩家可以通过鼠标或键盘输入数字，使用笔记模式记录候选值，检查冲突、获取提示、撤销操作，并在完成后看到计时结果。

前端负责棋盘渲染和交互状态管理，Tauri 原生侧负责题目生成、求解与提示逻辑，整体结构清晰，比较适合作为 React + Tauri 双端协作的小型示例。

## 功能亮点

- 支持 `简单 / 中等 / 困难 / 专家` 四档难度
- 9x9 棋盘交互，支持选中、输入、擦除
- 笔记模式，可为单元格记录候选数字
- 冲突高亮，帮助快速发现错误输入
- 同数字联动高亮，提升扫描效率
- 提示功能，可指出错误格或下一个可填格
- 检查、撤销、重置、新游戏等常用操作
- 内置计时器，完成后自动展示完成状态
- 支持键盘输入、删除、方向键移动与快捷切换
- Rust 侧生成唯一解题盘，并提供求解与提示能力

## 操作方式

### 鼠标操作

- 点击棋盘单元格进行选中
- 点击右侧数字键盘输入数字
- 点击“擦除”清空当前可编辑格
- 点击“提示 / 检查 / 撤销 / 重置 / 新游戏”执行对应动作

### 键盘操作

- `1-9`：输入数字
- `Backspace / Delete`：擦除
- `方向键`：移动当前选中格
- `N`：切换笔记模式
- `Ctrl+Z` / `Cmd+Z`：撤销

## 技术栈

- 桌面框架：Tauri 2
- 前端：React 18 + TypeScript + Vite
- 测试：Vitest + Testing Library + JSDOM
- 原生逻辑：Rust
- 数独算法：题盘生成、求解、冲突校验、提示

## 开发说明

前端核心交互集中在 `useSudoku.ts`：

- 管理棋盘、题解、笔记、冲突、提示、历史记录和计时状态
- 负责新游戏、输入、撤销、检查和重置流程
- 统一处理键盘事件与界面反馈

Rust 原生侧负责数独算法：

- 生成带唯一解的题盘
- 根据当前局面求解
- 返回提示位置和正确数字
- 校验冲突与合法性
